# Вопросы владельцу

Каждый вопрос имеет четыре варианта. У варианта есть описание, плюсы, минусы, сложность для ИИ (1–10), влияние на производительность, влияние на развитие и стоит ли его рекомендовать.

За один ответ закрывается один вопрос. Не выбирать пакетом «все рекомендованные», если владелец этого прямо не попросил: рекомендация не равна решению.
