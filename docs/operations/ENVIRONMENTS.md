# Среды

Боевого сервера нет. Этот файл задаёт границу, чтобы она не появилась случайно.

| Среда | Данные | Кто пишет экономику | Платежи |
|---|---|---|---|
| `dev` | Локальная или личная БД разработчика | Да, тестовые | Нет |
| `staging` | Отдельная БД, копия структуры, не копия боя без обезличивания | Да, тестовые | Только песочница магазина, если когда-нибудь включат |
| `prod` | Боевая | Только игровые и админские команды с аудитом | Боевой контур магазина, после PHASE-10 |

Правила:

- в клиенте адрес сервера собирается конфигом сборки, не зашит одной строкой на все среды;
- секрет среды лежит в хранилище среды, не в репозитории;
- бэкап `prod` проверяется восстановлением, а не фактом «файл создан». Пока `prod` нет, не утверждать, что резервное копирование работает;
- мониторинг и цель по месту на VPS 4 vCPU / 8 ГБ RAM / 60 ГБ SSD — ориентир стенда из постановки, не ёмкость по игрокам.

Нагрузочный тест и план отката описываются в фазе, которая первой поднимает общий сервер. Сейчас поднимать нечего.
