# PHASE-05. Вертикальный срез №3

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-04 `VERIFIED` и ответов D6.
- Блокеры: нет утверждённой физики и момента включения руля.

## Цель

Ручное управление одной машиной и одной операцией, не отменяющее автоназначение. Плюс износ, топливо и ремонт в пределах утверждённых вариантов D6.

## Состав

Одна управляемая машина. Сервер подтверждает завершение работы по правилам участка, а не по клиентскому «я уже вспахал». Автопилот той же операции остаётся и даёт тот же урожай. Ремонт и топливо списываются транзакцией. Модернизация только если Q-MECH-006 её включил, с узким потолком.

Классы техники из постановки не делать все. Один класс сверх трактора — только если срез №3 ещё играбелен. Иначе остальные классы — следующие итерации этого же этапа, отдельными записями в `ROAD.md`, без нового номера мира.

## Проверки

Пакет с подделанным урожаем не меняет склад. Ремонт не уводит баланс ниже нуля. Два исполнителя на одну операцию невозможны, пока Q-MECH-007 это запрещает. Автопилот и руль сходятся на контрольном поле в пределах записанного допуска по времени, не по деньгам.

## Критерий

На устройстве записан прогон: сцена, модель, FPS. Без записи нельзя писать, что руль «оптимизирован».

## Откат

Отключить ручной канал флагом контента, оставив автоназначение. Хозяйства не откатывать ради отключения руля.
