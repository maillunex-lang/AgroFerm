# PHASE-07. Вертикальный срез №5

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-04 `VERIFIED`, `APPROVED` ответ Q-WORLD-001, записка по лицензии геоданных.
- Блокеры: карта не выбрана, данные не импортированы.

## Цель

Обзор настоящей географии Башкортостана в утверждённом масштабе и первая логистика: рейс как таймер и груз, не колонна физических грузовиков. Региональная цена только в пределах утверждённого Q-ECON-013. Контракт на поставку с атомарным завершением.

## Состав

Импорт только тех слоёв, которые разрешила записка по лицензии. Атрибуция в клиенте, если использован OSM. Игровые участки не повторяют чужой кадастр. Стартовый район не запирает игрока навсегда, по правилу Q-WORLD-005.

Маршрут: откуда, куда, что, сколько, когда приедет, сколько стоит провоз. Срыв по недостаче виден до отправки.

## Проверки

Нельзя отправить больше, чем лежит на складе, и нельзя получить груз дважды. Цена сделки в коридоре, если коридор уже включён. Клиент старой версии контента карты не входит в мир. Атрибуция видна на экране карты.

## Критерий

Два стендовых хозяйства в разных точках данных проводят один рейс. Повторный вход посреди рейса не теряет груз и не клонирует его.

## Откат

Остановить новые рейсы флагом. Уже едущие либо доезжают, либо возвращают груз командой отката, записанной заранее в этой фазе. Не оставлять «груз нигде».
