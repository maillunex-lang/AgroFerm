# PHASE-09. Вертикальный срез №7

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-08 `VERIFIED`.
- Блокеры: ранняя экономика не доказана симулятором.

## Цель

Долгий цикл: завод с цепочкой и стоком, несколько площадок одного владельца как холдинг без совладельцев, исследования, специализации без единственной обязательной меты, сезонные события из админки, рейтинги по нескольким номинациям.

## Состав

Одна производственная цепочка сверх среза №4, не все из постановки сразу. Дерево исследований короткое. Специализации из списка постановки включаются только с описанным способом смены или с узким бонусом, чтобы не появилась одна мета. Событие: посевная или ярмарка, одно, с однократной наградой. Рейтинг без награды, которая даёт уникальный экономический станок.

Перед включением цепочки обязателен прогон экономического симулятора на суточном цикле и записанный вывод, куда деваются лишние деньги.

## Проверки

Повтор награды события не выдаётся. Здание вне участка не строится. Исследование не включается правкой поля в обход команды. Цепочка без названного стока не публикуется.

## Критерий

Игрок проходит один игровой сезон стенда от посева до события, журнал и рейтинг сходятся, симулятор не показывает неограниченный рост денег на контрольном сценарии.

## Откат

Событие выключается расписанием. Цепочка снимается с публикации. Уже произведённое остаётся у игроков, новые запуски останавливаются.
