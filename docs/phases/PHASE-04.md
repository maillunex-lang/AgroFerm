# PHASE-04. Вертикальный срез №2

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-03 в статусе `VERIFIED`.
- Блокеры: среза №1 нет.

## Цель

Хозяйство, в котором есть выбор на несколько минут вперёд, всё ещё без руля и без республики.

## Состав

Несколько полей в одной сцене. Культуры среза №2 по Q-FARM-002, когда он будет утверждён. Назначение работ. Автовыполнение без руля. Склад с пределом. Продажа NPC с лимитом. Карта одного района только если к этому моменту закрыты лицензии и Q-WORLD-001; иначе честный экран «района ещё нет», а не фальшивая география.

Почта награды с однократной выдачей. Работники, если Q-FARM-007 утвердит автопилот как назначение, а не как обязательный найм.

## Админка

Справочник культур, цены NPC, лимит скупки, вместимость склада, публикация черновика.

## Проверки

Переполнение склада не уничтожает урожай молча. Продажа по тому же `command_id` не платит дважды. Суточный лимит NPC нельзя обойти вторым запросом. Новая культура без публикации не видна клиенту.

## Критерий

Игрок за сессию засевает, дожидается или завершает работу по правилам времени D2, продаёт часть, перезаходит, остатки и деньги сходятся с журналом.

## Откат

Как у среза №1, плюс откат версии справочника на предыдущую публикацию.
