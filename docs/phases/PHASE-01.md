## Цель

Спецификации, по которым другой ИИ реализует систему, не гадая правила. Не портянка на все десять лет сразу.

## Порядок

1. Подробно: системы P0 и обучение первых пяти минут.
2. Подробно: культуры среза №2, поля, работники, склад, простая продажа.
3. Границы и админские поля для остального каталога, без ложной точности.
4. Карта экранов: все 28 экранов постановки помечаются срезом, в котором появятся. Макеты рисуются только для ближайшего среза.

Формулы урожайности, цен и таймеров попадают в GDD только после соответствующего `APPROVED` и помечаются как параметры админки.

## Результат

Файлы спецификаций в тематических каталогах `docs/`, ссылки из каталога систем, статус этапа в `ROAD.md`.

## Критерий выхода

У каждой P0-системы есть документ: правила, ошибки, данные, админка, проверка. Открытые вопросы не спрятаны внутри абзаца как будто они решены.
