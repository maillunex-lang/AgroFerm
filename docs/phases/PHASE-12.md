# PHASE-12. Подготовка релиза

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-11 и принятое владельцем содержание первого магазинного билда. Это может быть ранний срез, не обязательно холдинг. Релиз «всей постановки сразу» не планируется.
- Блокеры: нет кандидата билда, нет юридической оговорки Q-OPS-006, нет проверенного бэкапа.

## Цель

Сборку можно отдать людям вне автора: понятно, что это за игра, как войти, как уйти, что земля виртуальная, чьи картоданные, как сообщить о поломке.

## Состав

Подпись релиза вне git. Среды не перепутаны. Техработы показываются текстом. Обязательное обновление работает по Q-OPS-002. Локализация: русский как основной, строки не зашиты в логику там, где уже есть UI. Политика резервных копий проверена восстановлением. Мониторинг первого общего сервера включён.

Публикация в магазин — действие владельца, не автоматический итог зелёного CI.

## Проверки

Чистая установка на устройство. Новый аккаунт проходит туториал среза, который объявлен составом релиза. Старый билд получает отказ, если он несовместим. Секретов в git нет: поиск по репозиторию перед тегом.

## Критерий

Владелец принимает список известного и неизвестного. `VERIFIED` не означает «игра закончена». Он означает «этот билд можно показывать тем людям, для кого его собрали».

## Откат

Снять билд с выдачи или включить техработы. Базу не откатывать ради плохого клиента, если протокол ещё совместим. Если несовместим, игроков не пускать старым клиентом, а не чинить их молчаливой порчей сохранений.
