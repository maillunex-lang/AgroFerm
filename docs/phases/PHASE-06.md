# PHASE-06. Вертикальный срез №4

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-04 `VERIFIED`. Порядок относительно PHASE-05 по умолчанию последовательный, см. `ROAD.md`.
- Блокеры: нет спецификации даже одного вида животных.

## Цель

Один вид животных или одна первичная переработка, не вся таблица постановки. Жестоких сцен нет. Животные не умирают из-за офлайна: продукция останавливается.

## Состав

Кандидат на выбор в начале этапа, не сейчас: пасека как региональный колорит с низкой жестокостью, либо молоко с одним рецептом. Корм связан с культурой среза №2. Рецепт: вход, выход, время, здание, работник. Выход не больше входа по записанным коэффициентам. Коэффициенты в админке.

Остальные виды постановки (мясо, овцы, лошади, птица, кумыс) остаются в GDD списком и не входят в этот срез пакетом.

## Проверки

Рецепт не создаёт продукт из пустого склада. Повтор выдачи готовой партии не удваивает её. Офлайн на потолке времени не убивает поголовье и не печатает бесконечный продукт.

## Критерий

Игрок производит одну партию, продаёт или кладёт на склад, журнал сходится.

## Откат

Выключить рецепт публикацией предыдущего контента. Уже выданный продукт не удалять молча: компенсация только явной командой с аудитом.
