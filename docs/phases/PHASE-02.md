# PHASE-02. Техническая архитектура

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-01 для систем P0, ответы D10.
- Блокеры: стек не утвержден. Есть только [предварительная архитектура](../architecture/PRELIMINARY_ARCHITECTURE.md).

## Цель

Проект, по которому пишется срез №1: схема таблиц P0, команды API, формат сообщения, миграции, среды, минимальная админка. Не схема всех 40 систем.

## Состав

- ER только для таблиц среза №1.
- Деньги как `BIGINT`, когда валюта выбрана. Если D3 ещё открыт, в схеме нет выдуманной валюты, только пометка «ждёт Q-ECON-002».
- Список команд с идемпотентностью.
- Черновик Docker Compose без секретов.
- Решение по рендереру не входит сюда, пока нет прогона. Прогон — часть PHASE-03 или отдельная заметка, если сцена уже есть.

## Критерий выхода

Документ архитектуры P0 помечен как готовый к реализации. Владелец не обязан читать каждую таблицу, но Q-TECH, которые блокируют схему, закрыты.

Код всё ещё не пишется в этом этапе, кроме случая, если владелец отдельно откроет технический спайк. Спайк не сливается как игра.
