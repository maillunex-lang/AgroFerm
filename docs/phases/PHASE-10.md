# PHASE-10. Коммерческие системы

- Статус: `NOT_STARTED`
- Готовность: 0%
- Зависит от: PHASE-03 `VERIFIED`, ответы D9, отдельная юридическая проверка правил магазина. Не зависит от холдинга: косметику можно включить раньше поздних срезов, но не раньше живой игры и не внутри среза №1.
- Блокеры: нет витрины, которую разрешено продавать. Цен не существует.

## Цель

Магазин косметики и удобств без силы на рынке. Платежи через механизм площадки. Аналитика покупок без хранения лишних платёжных данных.

## Состав

Только то, что разрешит Q-MON-001. По умолчанию в рекомендациях: разовые облики, без подписки, без ускорения, без десяти уровней VIP, без сезонного пропуска, пока нет сезона. Каждый товар проходит список «это косметика» из Q-MON-005.

Сервер выдаёт товар после подтверждения платежа площадкой. Не наоборот.

## Проверки

Отменённый и поддельный чек не выдаёт товар. Повтор того же чека не выдаёт товар дважды. Возврат оставляет согласованное состояние и запись. В билде стенда нет боевого ключа магазина.

## Критерий

Песочница магазина проходит покупку и возврат на тестовом аккаунте. Боевой контур выключен, пока владелец отдельно не откроет прод.

## Откат

Выключить витрину флагом. Уже выданную косметику не отбирать без правила возврата. Игровые остатки зерна и денег из-за отката магазина не меняются, потому что магазин их не продаёт.
