# Офлайн-срез 0.1

Статус: играбельный прототип по прямой просьбе владельца. Это не онлайн и не утверждение карты республики.

На устройстве, без сервера:

- хозяйство «Наследие», три поля, одна культура — пшеница;
- трактор «Яик-28», вымышленная марка;
- вспашка, посев, рост, уборка, продажа по твёрдой цене;
- крыша амбара как первая трата;
- сохранение на устройстве, догон роста не больше двух часов;
- руль необязателен: по умолчанию трактор ведёт работу сам.

Скорость времени 1× / 3× / 8× влияет только на рост и небо, не на деньги.

Участок стилизован и подписан как Уфимский район. Это не кадастр и не право на землю.

Исходники экрана: `offline/game/`. Оболочка Android: `offline/android/`. Сборка APK подписывается отладочным ключом и в git не кладётся.
