# АгроБашкирия Online: Наследие земли

Массовая онлайн-игра: сельскохозяйственный симулятор, экономика и управление хозяйством на территории Республики Башкортостан.

Игрок проходит путь от маленькой фермы до аграрной корпорации в общем постоянном мире. Сервер — источник истины для хозяйства, ресурсов и рынка. Клиент показывает мир и принимает управление.

## Чего здесь нет

Клиента, сервера, админки и ассетов нет намеренно. Их нельзя начинать, пока не утверждены решения, от которых зависит первый вертикальный срез, и сам срез не описан как задание на реализацию.

Утверждённых продуктовых решений пока нет. Рекомендации в [DECISIONS.md](DECISIONS.md) имеют статус `PROPOSED`.
